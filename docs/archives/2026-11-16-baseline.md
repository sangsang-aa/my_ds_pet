## 已知缺陷与限制

### 1. `bounds.txt` 未按 `scale_factor` 缩放（P1）

- `desktop_pet_image/idle/bounds.txt` 第一行：`61 110 262 353`；
- 源画布 384×512；窗口/帧 269×358；期望缩放后约 `43 77 183 247`；
- `LoadFrameBounds` 原样赋值，`PresentFrame` 直接加到屏幕坐标，没有缩放/夹取；
- 后果：气泡水平中心偏右约 57 px；侧面气泡离身体更远；扫头带下移；
- 命中测试不受影响（mask 在缩放帧上生成）；
- 截至本快照未修复。

详细分析见 [`../architecture/06-decisions-and-risks.md#r1-bounds-未缩放p1`](../architecture/06-decisions-and-risks.md#r1-bounds-未缩放p1)。

### 2. 未注册动作

`idle2`、`busy`、`peek` 各有 30 帧，但不在 `behaviors.cpp`；`idle` 只有 1 帧。当前“随机待机”逻辑没有实际效果。详见 [R3](../architecture/06-decisions-and-risks.md#r3-未注册的动作)。

### 3. core → pet 反向依赖

`core/settings.cpp` include `pet/behaviors.h`，用于应用 `[action]` 段。单产品可用，但破坏分层。详见 [R4](../architecture/06-decisions-and-risks.md#r4-core--pet-反向依赖)。

### 4. `FullCycle` 时长不是精确上限

`walking_down` 目标 15~45 tick，但必须等到末帧；30 帧时常见 29 或 59 tick。详见 [R6](../architecture/06-decisions-and-risks.md#r6-fullcycle-的时长下限)。

### 5. `shy` 冷却短于动画

冷却 25 tick，动画 40 帧；后半段可被再次扫头重启。详见 [R8](../architecture/06-decisions-and-risks.md#r8-shy-冷却与动画长度)。

### 6. INI 行尾注释不可用

README 示例的行尾 `;` 会让整段解析失败并回退默认。详见 [R12](../architecture/06-decisions-and-risks.md#r12-ini-行尾注释与范围校验)。

### 7. 其他

多显示器、DPI 变化、全量预载、无 Win32 自动化测试、`__argv` 编码、`OnDragEnd` 未接线等，见
[`../architecture/06-decisions-and-risks.md`](../architecture/06-decisions-and-risks.md) 的完整风险表。
