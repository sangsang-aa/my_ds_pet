# 鲸鱼少女 Spine 静态拆件 · 返工版

共 95 个透明 PNG：front 46 件、side 28 件、back 21 件。

## 从哪里开始

先看 preview.jpg 和每个视角的 parts-dark.jpg。深色底预览用于看白边，PNG 本身都是透明背景。
每个视角包含：
- parts/：裁紧的 RGBA PNG，外侧保留透明留边；正面手臂/袖口是图集原尺寸（1–2 像素留边），其余大多是 2 像素。
- *-clean.psd：同一画布上按实际位置排好的独立图层，方便继续修图。
- *-setup-spine42.json：按 Spine 4.2 数据结构写出的初始骨骼与 region 附件，图片路径为同级 parts/。
- layout.json / parts.csv：坐标、层序、建议轴心、父级与补绘来源。
- assembled.png：重组预览，保留透明背景。

### 手臂美术：原生分辨率，不随图集

`parts/` 是美术底片，`atlas` 是运行纹理。2026-10-22 曾把 6 块手臂/袖口按图集裁剪
覆盖过一次（`d642d69`），现已从 `950f06a` 恢复原生尺寸：

| 零件 | 原生 PNG | 图集区域 | 说明 |
|---|---|---|---|
| 大臂 左/右 | 108×137 / 104×136 | 118×173 / 113×172 | 图集按显示尺寸重采样 |
| 小臂 左/右 | 103×123 / 108×124 | 112×155 / 118×157 | 同上 |
| 毛袖口 左/右 | 99×100 / 99×100 | 108×126 / 108×126 | 同上 |

`layout.json` 的 `expected_differences` 逐条记录这种差异（含 `ratio` 与原因），
`parts[].source` 区分 `native`（原生底片）和 `atlas-derived`（只能从图集切出，
如袜子、眉毛）。**禁止把图集区域覆盖回 `parts/`**：那会把一次重采样固化成唯一
副本。`spine/tools/sync_parts.py` 因此默认只读，必须显式 `--write`。

### 已接受的差异（不再修）

| 位置 | 现状 | 判断 |
|---|---|---|
| 正面手臂 6 件 | 图集 = 包内 ×1.09 / ×1.26 | **有意为之，不再修**。正面要更贴合需要更多关节，且天花板在源图分辨率 |
| 侧面 `coat_fur_trim` | 包里 391×190，图集 372×182，左端绒球刻意裁掉 | 该处被头发与手覆盖；用原生件重切后整幅可见差异仅 0.93%，不修 |
| 侧面 `eyebrow` | 68×24 vs 65×24（1.046×） | 肉眼不可见，修它要动图集，收益为负 |

`collar`（0.922 纵向）没有刚性参照，冻结不动，避免引入二次采样。

`layout.json` 的 `expected_differences` 继续列出这些：正面 7 条（6 手臂 + collar）、
侧面 2 条（`coat_fur_trim`、`eyebrow`）、背面 0 条。它们是**记录，不是待办**，
不要为了"视觉统一"回头改。

### 重打包图集：暂缓（受限于源图分辨率）

按原生尺寸重打包图集可以让"缩放只留在 json 一处"，2026-10-22 在 `/tmp` 做过完整
对比，结论是**受限于源图分辨率**，暂不执行：

- 原生手臂只有 108×137，显示尺寸是 118×173，任何路径都必须插值；
- 重打包后由运行时双线性插值：内部像素差 `|Δ|>8` 占 16%，边缘梯度 −2.3%~−3.3%，
  达不到"内部差异 > 98%、梯度不下降"的验收线；
- 中心偏移可控制在 0.5 px 内，并排目视几乎无差别，但没有清晰度收益。

等有比显示尺寸更大的原生手臂素材再开。

`validation.json` 的 `checks` 记录了逐项核对结果；其中 `psd_pixel_roundtrip`
标注为「未重跑」，因为这轮没有重建 PSD。

## 使用范围与已知差异

这是静态美术拆件和初始定位数据，不是已经绑定好权重的 Spine 工程，也不包含动作关键帧。Spine 4.2 JSON 已检查图片引用、层序、尺寸和父级，尚未在 Spine 编辑器中实机导入验证。
遮挡区与缺损处采用静态补绘，因此部分发束形状、衣服印花、毛领和袖子与原图存在差异。PSD 可继续细修。三个视角是三套独立二维素材，不能直接通过骨骼旋转互相变成另一视角。
画布坐标以左上角为原点，x 向右、y 向下；left/right 指画面左右。建议先完成正面绑定，再为侧面及背面配置替换附件或独立骨架。
小幅摆动可使用骨骼与网格；大幅抬臂、转头等仍需按实际动作检查遮挡和关节搭接。
